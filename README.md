# コアイメージ英語

英単語・中学英文法・句動詞を、**丸暗記ではなくコアイメージから**学ぶスマホ向け学習アプリ。

### ▶ https://sora3141.github.io/core-image-english/

スマホのブラウザでそのまま使えます。インストール不要、進捗は端末内に保存されます。

ローカルで動かす場合も `index.html` を開くだけ。ビルドも依存関係もありません。

## 考え方

`on` は「上」ではなく【接触】。これ1つで、バラバラに見えた用法がつながります。

```
on the wall      壁に接触
on the ceiling   天井に接触（むしろ下）
on Monday        時間軸に接触
turn on          回路が接触 → 通電
put on           体に接触 → 着る
go on            接触が続く → 継続
depend on        寄りかかって接触
It's on me.      負担が私に乗っている → おごり
```

暗記8個が、理解1個になります。

さらに句動詞は、**不変化詞のコア × 動詞のコアの掛け算**でできています。

```
           on          off         up          out         down
        (接触)      (分離)      (上へ)      (内→外)     (下へ)
    ──────────────────────────────────────────────────────────
    put   着る       延期する     建てる      消す       書き留める
    get   乗る       降りる       起きる      抜け出す    落ち込む
    take  引き受ける  脱ぐ/離陸    始める      持ち出す    取り壊す
```

「300個の熟語」ではなく「50個のコアの交点」として学びます。

文法も同じ原理で説明できます。**過去形のコアは「距離」**です。

```
時間的な距離   I went there.          過去のこと
現実からの距離  If I were you...       仮定法 ＝ 現実ではない
心理的な距離   Could you help me?     丁寧 ＝ 相手に踏み込まない
```

学校では別々の単元として習う「時制」「仮定法」「丁寧表現」は、正体が同じものです。

## 機能

### 📖 教科書
- コア図（SVG）→ 派生用法 → ⚡豆知識、の構成
- 冒頭に派生へジャンプするチップ列。スクロールに追従して現在地が光る
- ダークモード自動対応

### ✍️ 演習
1画面で完結し、スクロールなしで回せます。

| 形式 | 内容 |
|---|---|
| コア適用 | 教科書に出てこない用法を見せて、どのイメージかを選ぶ |
| 用法穴埋め | 前置詞・不定詞/動名詞・冠詞・時制を選ぶ |
| 意味選択 | 句動詞・単語の意味を選ぶ |

**誤答の選択肢は「コアを取り違えたときに選んでしまうもの」だけ**で構成しています。
ランダムな誤答だと消去法で解けてしまい、理解ではなく勘を測ることになるためです。

間違えると解説が出て、該当する派生用法へ1タップで飛べます。
ページをまたぐ問題もあり、例えば `in` のページで `on time` を答えさせ、
解説は `on` のコアへ飛ばします。

### ▦ 句動詞マトリクス
動詞30 × 不変化詞25 ＝ 750マスの空間を、そのまま目で見る画面です。

- **俯瞰マップ** — 750マス全体が1画面に収まります。
  `up` `out` `off` `on` の列が濃く、右へ行くほど疎になる分布がそのまま見えます
- **動詞を選ぶ** と、その動詞の句動詞がカードで並びます。
  意味を**先に自分で推測してから**開くと、コアが身についているか確かめられます
- 詳細には「動詞のコア × 不変化詞のコア」を必ず併記し、両方のページへ飛べます
- **空白も情報です。** `from` `about` `of` `under` `between` は句動詞を1つも作りません。
  前置詞ではあっても、動詞にくっつく副詞辞にはならないからです。
  `have` の行がほぼ空なのも、「圏内にあるだけで動きがない」ため

### 🔁 復習
間隔反復（0 → 1 → 3 → 7 → 21 → 60日）。誤答で間隔がリセットされます。
進捗は localStorage に保存されるので、サーバーは不要です。

## ファイル構成

```
index.html          アプリ本体
style.css           スマホ縦持ち・片手前提のスタイル
app.js              画面遷移・採点・SRS・マトリクス
diagrams.js         コア図28点（CSS変数を参照するのでテーマ追従）
data/particles.js   不変化詞10ページ
data/verbs.js       基本動詞8ページ
data/grammar.js     文法10ページ
data/phrasals.js    句動詞マトリクス
data/exercises.js   演習226問
DESIGN.md           設計メモ（決定事項・見送った案の記録）
```

コンテンツはすべてデータファイルに分離してあるので、
ページや問題の追加は `data/` を編集するだけで済みます。
