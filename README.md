# コアイメージ英語

英単語・中学英文法・句動詞を、**丸暗記ではなくコアイメージから**学ぶスマホ向け学習アプリ。

### ▶ https://sora3141.github.io/core-image-english/

スマホのブラウザでそのまま使えます。進捗は端末内に保存されます。

**アプリとしてインストールできます。** Chrome なら画面内の「📲 アプリとして追加」か、
アドレスバーのインストールアイコンから。iPhone の Safari なら 共有 → ホーム画面に追加。
インストールすると、**電波がなくても全ページ・全問題が使えます**（Service Worker が
全データをキャッシュするため。通学中の学習を想定しています）。

ローカルで動かす場合も `index.html` を開くだけ。ビルドも依存関係もありません。

## 考え方

`on` は「上」ではなく【接触】。これ1つで、バラバラに見えた用法がつながります。

```
on the wall      壁に接触
on the ceiling   天井に接触（むしろ下）
on Monday        時間軸に接触
turn on          回路が接触 → 通電
put on           体に接触 → 着る
go on            接触が続く → 継続
depend on        寄りかかって接触
It's on me.      負担が私に乗っている → おごり
```

暗記8個が、理解1個になります。

さらに句動詞は、**不変化詞のコア × 動詞のコアの掛け算**でできています。

```
           on          off         up          out         down
        (接触)      (分離)      (上へ)      (内→外)     (下へ)
    ──────────────────────────────────────────────────────────
    put   着る       延期する     建てる      消す       書き留める
    get   乗る       降りる       起きる      抜け出す    落ち込む
    take  引き受ける  脱ぐ/離陸    始める      持ち出す    取り壊す
```

「300個の熟語」ではなく「50個のコアの交点」として学びます。

文法も同じ原理で説明できます。**過去形のコアは「距離」**です。

```
時間的な距離   I went there.          過去のこと
現実からの距離  If I were you...       仮定法 ＝ 現実ではない
心理的な距離   Could you help me?     丁寧 ＝ 相手に踏み込まない
```

学校では別々の単元として習う「時制」「仮定法」「丁寧表現」は、正体が同じものです。

## 機能

### 📖 教科書
- コア図（SVG）→ 派生用法 → ⚡豆知識、の構成
- 冒頭に派生へジャンプするチップ列。スクロールに追従して現在地が光る
- ダークモード自動対応

### ✍️ 演習
1画面で完結し、スクロールなしで回せます。

| 形式 | 内容 |
|---|---|
| コア適用 | 教科書に出てこない用法を見せて、どのイメージかを選ぶ |
| 用法穴埋め | 前置詞・不定詞/動名詞・冠詞・時制を選ぶ |
| 意味選択 | 句動詞・単語の意味を選ぶ |

**範囲を絞って出題できます。** すべて／不変化詞／基本動詞／文法／紛らわしい語。
「文法だけ集中的に」といった回し方ができます。

**誤答の選択肢は「コアを取り違えたときに選んでしまうもの」だけ**で構成しています。
ランダムな誤答だと消去法で解けてしまい、理解ではなく勘を測ることになるためです。

間違えると解説が出て、該当する派生用法へ1タップで飛べます。
ページをまたぐ問題もあり、例えば `in` のページで `on time` を答えさせ、
解説は `on` のコアへ飛ばします。

### ▦ 句動詞マトリクス
動詞30 × 不変化詞25 ＝ 750マスの空間を、そのまま目で見る画面です。

- **俯瞰マップ** — 750マス全体が1画面に収まります。
  `up` `out` `off` `on` の列が濃く、右へ行くほど疎になる分布がそのまま見えます
- **動詞を選ぶ** と、その動詞の句動詞がカードで並びます。
  意味を**先に自分で推測してから**開くと、コアが身についているか確かめられます
- 詳細には「動詞のコア × 不変化詞のコア」を必ず併記し、両方のページへ飛べます
- **空白も情報です。** `from` `about` `of` `under` `between` は句動詞を1つも作りません。
  前置詞ではあっても、動詞にくっつく副詞辞にはならないからです。
  `have` の行がほぼ空なのも、「圏内にあるだけで動きがない」ため

### 🔤 単語
NGSL（New General Service List）頻度順の上位1000語。
**テスト**と**単語帳**を切り替えて使います。

#### 単語帳
問われずに、ただ眺めて調べられる場所です。

- 帯（1〜333位 / 334〜666位 / 667〜1000位）ごとに一覧
- **単語・訳・例文から検索**（検索中は帯をまたぎます）
- すべて / 未出題 / 間違えた / 正解済み / 絵あり で絞り込み
- 行をタップすると、**イメージ図・発音記号・意味ごとの例文・豆知識・
  コアページへのリンク**が開きます
- 左端の番号が、正解済みなら緑、間違えたなら赤に変わります

#### イメージ図（357語）
インラインSVGで描いてあるので、拡大しても粗くならず、
テーマの明暗にもアクセント色にも自動で馴染みます。

**1000語の3語に1語**（357語）に絵がついています。
うち**109語は2枚並べ**で、使い分けは2通りあります。

**意味が2つある語**は、その2つを左右に置きます。
`bank` なら「銀行」と「土手」、`arm` なら「腕」と「武器」、
`store` なら「店」と「蓄える」、`field` なら「野原」と「分野」。
右側のラベルには、なぜその意味になるかを一言添えてあります
（field の「分野」なら〈守備範囲〉、ground の「根拠」なら〈土台〉）。

**反対語がある語**は、右に反対語を置きます。
`big`↔small、`long`↔short、`hot`↔cold、`new`↔old、`strong`↔weak。
1語だけ見るより、対で見たほうが輪郭がはっきりします。

絵にしにくそうな語ほど、絵にする値打ちがあります。

- **位置の語** — `middle` `side` `center` `above` `below` `behind`
  `across` `along` `toward` `beyond` `ahead`。
  訳語の「〜の方へ」より、基準と矢印のほうが速く伝わります。
  `toward` には〈着くとは限らない〉と添えてあります
- **時間の語** — `yesterday` `tomorrow` は時間軸の上に3日を並べ、
  どれを指しているかを塗り分けます。`minute` と `hour` は長針と短針、
  `month` はカレンダー、`weekend` は7日のうち後ろ2日
- **家族の語** — `father` `mother` `son` `daughter` `brother` `sister`
  `wife` `husband`。誰から見た誰なのかを、線と矢印と濃淡で示します。
  訳語だけだと son と daughter のどちらが「親から見た」のか迷いません
- **役割の語** — `leader` は旗を持って先頭に、`manager` は組織図の上に、
  `member` は輪の内側に、`agent` は二者のあいだに置きます。
  どれも「人」の絵ですが、**どこに立っているか**が違います
- **抽象の語** — `limit` は壁とその先の✕、`range` は端から端までの幅、
  `pressure` は上から押さえる矢印、`average` は棒グラフを横切る破線。
  日本語訳が同じでも、図にすると別物だと分かります
- **同じ軸の上で比べる語** — `past` `present` `future` は
  1本の時間軸のどこを太くするかだけが違います。
  `moment` は幅のない一点、`period` は始まりと終わりのある区間、
  `century` は10年×10。`begin` と `end` は同じ線の両端です
- **同じ入れ物で比べる語** — `all` `some` `many` `few` `most` `least`
  `more` `less` は、同じ円や同じ棒グラフの中身だけを変えています。
  1語ずつ別の絵にすると、かえって関係が見えません

#### テスト

- **3モード** — 英→日の4択 ・ 日→英の4択 ・ スペル入力
- 帯（1〜333位 / 334〜666位 / 667〜1000位）を選んで出題
- 誤答の選択肢は**同じ帯から引く**ので、難易度がそろいます
- **1000語のうち66語は教科書にコアページを持っています。**
  その語が出たときは暗記せず、答え合わせの画面からコアページへ飛べます
- 発音記号と例文つき。スペル入力では例文の該当語が空所になります
- **意味が複数ある語は、意味の数だけ例文が出ます。**
  `turn` なら 回る／曲がる／順番 の3つ、`see` なら 見る／わかる の2つ。
  213語・537例文ぶん用意しています。
  **2枚組の図がある語には、必ず2つ以上の例文があります**
  （図が2つの意味を約束している以上、例文も揃っていないと嘘になるため）
- 答え合わせは**1画面に収まる**ようにしてあります。4択は2×2、
  「次へ」は下に貼りついているので、例文が多い語でも探しに行かずに押せます
- **⚡豆知識とイメージ図は「次へ」の下**に出ます。
  先へ進む操作は画面内に残したまま、読み物は読みたい人だけが下へ送る形です。
  スクロールの意味が「進むため」ではなく「読むため」になります

### ⚙ 設定
どの画面からでも、見出しの右の歯車から開けます。

- **明るさ** — 自動（端末に合わせる）／ライト／ダーク
- **文字の大きさ** — 小・標準・大・特大。余白は変えず文字だけが大きくなります
- **色** — 土・藍・苔・菫・紅の5色。見本がその場で変わります
- **1回に出す数** — 5／10／20問
- **正解・不正解のときに震わせる** — オン／オフ
- **記録をすべて消す** — 確認をはさみます。設定は残ります

設定は最初の描画より前に反映されるので、起動時に前の見た目が一瞬見えることはありません。

### 📑 ジャンルで切り替え
教科書は107ページあるので、一続きにすると下まで行くのが大変です。
**不変化詞 / 基本動詞 / 文法 / 紛らわしい語** のタブで切り替えます。

- タブには件数が入り、下にそのジャンルの進捗バーが出ます
- **タブは上に貼りつく**ので、リストの途中からでも別のジャンルへ移れます
- 40ページある文法は、さらに **時制 / 文型と語順 / 動詞の後ろ / 比較 / つなぐ / その他**
  の小見出しで分かれています
- 最後に見ていたジャンルは覚えているので、次に開いたときもそこから

### 🔍 検索
教科書タブの上にあります。見出し語だけでなく、**コア・派生・例文・豆知識まで横断**します。
「接触」で引けば `on` `in` `off` `against` `get` `put` が出て、
**なぜヒットしたか**（コアなのか、豆知識なのか、例文なのか）も一緒に出ます。
107ページから目当てを引くための入口です。**検索中はジャンルを越えて**探します。

### 🔁 復習
間隔反復（0 → 1 → 3 → 7 → 21 → 60日）。誤答で間隔がリセットされます。
進捗は localStorage に保存されるので、サーバーは不要です。

## ファイル構成

```
index.html          アプリ本体
manifest.webmanifest  PWA の設定（名前・アイコン・表示モード）
sw.js               Service Worker（オフライン用。更新は自動で反映される）
icons/              アプリアイコン一式
style.css           スマホ縦持ち・片手前提のスタイル
app.js              画面遷移・採点・SRS・マトリクス
diagrams.js         コア図28点（CSS変数を参照するのでテーマ追従）
data/particles.js   不変化詞25ページ
data/verbs.js       基本動詞30ページ
data/grammar.js     文法40ページ
data/words.js       紛らわしい語12ページ
data/phrasals.js    句動詞マトリクス269
data/vocab.js       単語1000（NGSL 上位1000語）
data/vocab-senses.js  意味ごとの例文（227語・565例文）と豆知識（84語）
data/vocab-art.js     単語のイメージ図（357語・インラインSVG）
data/exercises.js   演習858問
DESIGN.md           設計メモ（決定事項・見送った案の記録）
```

コンテンツはすべてデータファイルに分離してあるので、
ページや問題の追加は `data/` を編集するだけで済みます。

## データの出典

このリポジトリは、コード以外に外部のデータを含みます。

| 対象 | 出典 | ライセンス |
|---|---|---|
| 単語リストと頻度順（`data/vocab.js`） | [NGSL](https://www.newgeneralservicelist.com/) — Browne, C., Culligan, B. & Phillips, J. | CC BY 3.0 |
| 発音記号（`data/vocab.js`） | [open-dict-data/ipa-dict](https://github.com/open-dict-data/ipa-dict) | MIT |
| 日本語訳・例文（`data/vocab.js`） | 本プロジェクトで付与 | MIT |
| 教科書・演習・句動詞の全テキスト | 本プロジェクトで作成 | MIT |

`data/vocab.js` は NGSL の上位1000語を抜き出したものです。
元データの並びには2つの癖があります（`the` が1位ではなく1000位に置かれ、`I` が収録されていない）。
姉妹プロジェクト `ngsl-vocab-quiz` と同じ並びを保つため、ここでは直していません。
`the` は冠詞ページで深く扱っています。

## 今後

当初の3本柱（単語1000・中学英文法・句動詞）は、ひと通り揃いました。

- 不変化詞 `after` / `behind`（`look after` / `leave behind` をマトリクスに載せるため）
- 紛らわしい語の追加（make/do、in time/on time など）
- 語彙を1000語より先へ（NGSL は2801語ある）
